
# Bank System API


API endpoints with the following functionalities Add New User, Balance Inquiry, Withdraw Cash, Deposit, Transfer Money


## Getting Started

1. git clone https://github.com/AdrielPotato/BankSystemAPI.git
2. replace the SQLServer connection string in appSettings.development.json to your own connection
3. Set the startup project of the solution to BankSystemAPI
4. Open package manager console and set the default project to Infrastructure\BankSystem.Infrastructure
5. Run Update-Database on the Package manager console.
```bash
  Update-Database
```
6. run solution and use the endpoints
